# Security policy

## Supported versions

Security fixes go to the `main` branch and the next release. Older releases are not patched, so update to the [latest release](https://github.com/etcherfx/sol-trade/releases/latest) or `main`.

## Reporting a vulnerability

Report vulnerabilities privately through the repository's Security tab → **Report a vulnerability** ([open a private report](https://github.com/etcherfx/sol-trade/security/advisories/new)). Please don't open a public issue for a security problem.

Describe the problem, how to reproduce it and what an attacker could do with it. Never include a real private key, `.env` file or API key in a report.
